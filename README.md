# 블랙박스 AI 과실비율 탐지 — 무료 온라인 버전

Streamlit Community Cloud의 실행 파일은 `cloud_app.py`, Python 버전은 3.12입니다.
기존 온라인 주소의 `app.py`는 새 화면 `cloud_app.py`를 실행하는 진입점입니다. 이전 구현은 Git 기록에 보존됩니다.

- 기존 Spline 로봇과 버튼 기반 화면 전환을 유지합니다.
- 영상은 실제 Python 분석 엔진이 처리합니다. 별도 AI 서비스 API 키가 필요하지 않습니다.
- 무료 서버용 초기 제한: 20MB, 60초, 1280×720, 1,800프레임, 서버 전체 동시 분석 1건.
- 결과는 접속 세션별로 분리하며 임시 파일은 처리 완료 후 15분 뒤 삭제합니다.
- 원본 영상은 처리 종료 후 삭제합니다. 모델은 첫 분석 때 내려받습니다.
- 무료 서비스의 절전과 자원 제한 때문에 최초 실행 지연이나 분석 중단이 있을 수 있습니다.

화면 파일은 frontend 폴더 또는 cloud_app.py와 같은 폴더에 둡니다.
서버는 필요한 HTML/CSS/JS만 별도 임시 디렉터리에 복사해 화면을 제공합니다.
영상, 사용자 결과, 연결 키, 로컬 환경 파일은 저장소에 올리지 않습니다.

로컬 실행: `python -m streamlit run cloud_app.py`

판정 비율은 제공된 규칙에 따른 추정이며 확정적인 법적 판단이 아닙니다.
